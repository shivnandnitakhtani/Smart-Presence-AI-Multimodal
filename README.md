# Smart Presence AI

**Smart Presence AI** is a lightweight, real-time Multimodal Attendance and Engagement Tracking Agent designed and developed by **Shivnandni Takhtani**.

## Key Features
- **Zero-Bloat Serverless Architecture**: Runs directly in the browser using Edge Vision heuristics and optional **Gemini 2.5 Flash Multimodal API** integration—no heavy server-side dependencies (`opencv`/`tensorflow`), guaranteeing instant deployment on **Vercel**.
- **Real-Time Engagement Telemetry**: Tracks participant presence, live engagement score timeline, affective state, and gaze vector.
- **Built-in Virtual AI Demo Mode**: Test and demonstrate the system seamlessly even without a webcam or API key.
- **Instant CSV Reporting**: One-click export of session attendance and engagement logs.
